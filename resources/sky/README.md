# Sky map (optional)

Drop an equirectangular (2:1) star map here as `sky.jpg` (or `sky.png`) and the app will use it
instead of the procedural stars (pick "Texture" in the Sky panel). Not committed to git because
these are large files; see the top-level README for credits if you use one.

Good free sources for education: NASA SVS "Deep Star Maps" (Tycho/Gaia based) and ESA/Gaia sky
maps. Check the license of whichever you pick and credit it in the video.
